# Asha Telegram Bot

Телеграм-бот для фотоквеста: участники получают задания, отправляют фото или видео-ответы и проходят испытания до 22:00.

## Особенности

- выдача случайного задания из общего файла `tasks.txt`
- сохранение фото и видео-ответов и времени отправки
- поддержка примеров фото и видео в заданиях
- подтверждение финального ответа перед фиксацией
- админский интерфейс для проверки заявок
- автоматическое завершение фотоквеста в 22:00
- развёртывание через Docker

## Файлы проекта

- `bot.py` — основная логика бота
- `db.py` — хранение данных в SQLite
- `config.py` — загрузка настроек из `.env`
- `tasks.txt` — банк заданий (по одному заданию на строку, с поддержкой примеров фото и видео через `||`)
- `Dockerfile` — контейнерная сборка
- `docker-compose.yml` — запуск сервиса
- `README.md` — инструкция

## Настройка

1. Скопируйте `.env.example` в `.env`:

```powershell
copy .env.example .env
```

2. Укажите токен бота и Telegram ID администратора:

```env
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_ID=123456789
```

3. При необходимости отредактируйте `tasks.txt`.

### Формат `tasks.txt`

Каждая строка — одно задание. Можно добавить примеры фото и/или видео через `||`:

```text
Сфотографируй вход в здание||photos/example.jpg
Найди и снять видео танца||videos/example.mp4
Повтори позу из примера||photos/pose.jpg||videos/pose.mp4
Просто напиши текст задания без примеров
```

Поддерживаются:
- **фото**: `.jpg`, `.jpeg`, `.png`, `.gif`
- **видео**: `.mp4`, `.mov`, `.avi`, `.mkv`, `.webm`, `.flv`
- **URL**: `https://example.com/photo.jpg` (прямые ссылки)
- **локальные пути**: `photos/example.jpg`, `videos/example.mp4`

## Локальный запуск

```powershell
pip install -r requirements.txt
python bot.py
```

## Запуск через Docker

```powershell
docker-compose up --build -d
```

## Команды

- `/start` — начать фотоквест и получить задание
- `/cancel` — отменить текущее действие
- `/admin` — открыть админ-меню (только админ)
- `/grantadmin <telegram_id>` — выдать права администратора

## Админские возможности

- просмотр списка участников
- проверка ожидающих модерации фото и видео-ответов
- отметка заявки как принятой или отклонённой
- рейтинг участников по количеству одобренных заданий
- подробная статистика фотоквеста (всего заданий, одобрено, отклонено, в ожидании)
- добавление новых заданий прямо из админ-панели (с фото, видео или без)
- ручное завершение квеста

## Добавление заданий через админ-панель

1. Нажми `/admin`
2. Нажми кнопку **"Добавить задание"**
3. Напиши текст задания
4. Отправь фото (опционально)
5. Отправь видео (опционально) или нажми **"Готово"**
6. Задание будет добавлено к списку и станет доступным для участников

Новые задания автоматически сохраняются в файл `tasks.txt`.

## Завершение квеста

Администратор может завершить квест вручную в любой момент:
1. Нажми `/admin`
2. Нажми кнопку **"🛑 Завершить квест"**
3. Все участники получат уведомление о завершении квеста и больше не смогут отправлять ответы

## Примечания

- база данных создаётся в `data/bot.db`
- фото сохраняются в `photos/`
- видео сохраняются в `videos/`
- `tasks.txt` должен содержать задания по одной строке
- бот перестаёт принимать ответы после 22:00 текущего дня
